# Экранки, а не настолки для своих

Сборник онлайн-игр для компании до 20 человек — по мотивам meme-police.com/bg.
Создаёте комнату, кидаете ссылку друзьям, созваниваетесь в Discord/Telegram — играете.

**Игры:** Коднеймс · Элиас · Шпион · Кто я? · Намёк понял · Викторина · Ответ большинства · Кости 1000

- Комнаты по ссылке `/r/ABCD`, без регистрации
- Вход в один шаг: никнейм (обязательно), реальное имя (по желанию — видно при наведении на аватар) и своё фото с кадрированием под круг. Тот же ник с другого устройства занимает своё прежнее место в комнате
- Три темы: тёмная, светлая и чёрная (OLED)
- «В лобби» не ломает игру: она встаёт на паузу, хост может вернуться к ней
- Управление хоста — шестерёнка в правом нижнем углу: пауза и перезапуск таймера, перемешать команды, новая доска, передать ход
- База из 1000 простых слов (`server/words.js`, исходник по темам — `server/words_base.txt`)
- 🏆 Марафон: готовые наборы («Разминка», «На час», «Весь вечер») или свой — игры, порядок, число каток и примерная длительность; после каждой катки — очки, в конце — турнирная таблица (1-е место 3 очка, 2-е — 2, 3-е — 1)
- Хост: выбирает игру, настройки, может выгнать игрока или передать права
- Переподключение: закрыл вкладку или пропал интернет — вернёшься на своё место
- Подарки и шалости за монеты (кнопка с сердечком): 300 монет за каждые 10 минут игры, 9 подарков с анимациями на аватарках
- Адаптив под телефон
- Свои слова можно добавить прямо в настройках игры
- Всё хранится в памяти сервера — базы данных не нужно

## Запуск у себя на компьютере

Нужен Node.js 18+ (https://nodejs.org).

```bash
npm install
npm start
```

Откройте http://localhost:3000. Чтобы позвать друзей с другой сети, задеплойте на хостинг (ниже).

Проверка, что всё работает (сервер должен быть запущен): `npm test`.

## Бесплатный хостинг: Render (рекомендую)

**Пошаговая инструкция — в [DEPLOY.md](DEPLOY.md).** Кратко: репозиторий на GitHub → кнопка `https://render.com/deploy?repo=<ссылка на репозиторий>`.

Без банковской карты, поддерживает WebSocket, есть регион Франкфурт.

**Ограничения бесплатного тарифа:** если 15 минут никто не играет, сервер засыпает, и первое открытие сайта после этого занимает ~1 минуту. Пока кто-то сидит в комнате, сервер не засыпает. Когда он уснул, комнаты пропадают — просто создайте новую.

1. Заведите аккаунт на https://github.com и создайте **новый репозиторий** (можно приватный).
2. Загрузите туда содержимое этой папки: на странице репозитория → **Add file → Upload files** → перетащите всё, **кроме** папки `node_modules`. Нажмите **Commit changes**.
3. Зайдите на https://render.com → **Sign in with GitHub**.
4. **New → Blueprint** → выберите свой репозиторий → **Apply**. Render сам прочитает `render.yaml`.
   (Или вручную: **New → Web Service** → репозиторий → Runtime: Node, Build: `npm ci --omit=dev`, Start: `node server/index.js`, Instance type: **Free**.)
5. Через 2–3 минуты появится адрес вида `https://party-games-xxxx.onrender.com` — это ваш сайт.

Обновления: меняете файлы в GitHub → Render сам пересобирает.

## Другие варианты

| Вариант | Цена | Плюсы | Минусы |
|---|---|---|---|
| **Render Free** | 0 | проще всего, без карты | засыпает через 15 мин простоя |
| **Koyeb Free** | 0 | 1 бесплатный сервис, регион Франкфурт | нужна карта (временная блокировка суммы для проверки) |
| **Oracle Cloud Always Free** | 0 | полноценный сервер, не засыпает | нужна карта, ручная настройка Linux |
| Любой VPS | несколько $/мес | не засыпает, полный контроль | нужно настраивать сервер |

**Koyeb:** Create Web Service → GitHub → выберите репозиторий → Builder: Dockerfile → Instance: Free → регион Frankfurt.

**VPS / Oracle (Docker):**
```bash
git clone <ваш-репозиторий> party-games && cd party-games
docker build -t party-games .
docker run -d --restart=always -p 80:3000 --name party-games party-games
```
Для HTTPS поставьте перед ним Caddy (`caddy reverse-proxy --from your.domain --to :3000`).

## Демо без сервера

`node demo/build.js` собирает `demo/party-games-demo.html` — один файл, вся логика в браузере, внизу панель «Смотреть как» для переключения между игроками.

## Аватарки

Фото кадрируется прямо в браузере (квадрат 256×256), сервер хранит его в памяти и раздаёт по короткой ссылке `/av/<хеш>` (`server/avatars.js`). После перезапуска сервера фото загружается заново с устройства игрока; без фото показываются инициалы.

## Как добавить слова и персонажей

Все словари — в `server/words.js`:
- `WORDS` — для Коднеймс, Элиаса и «Намёк понял» (только одиночные слова)
- `server/quiz_questions.js` — 700 вопросов для «Викторины» (ответ — число)
- `server/majority_questions.js` — 500 простых вопросов для «Ответа большинства» (совпадения приносят очки)
- `CHARACTERS` — для «Кто я?»
- `LOCATIONS` — локации и роли для «Шпиона»

Просто допишите через запятую. Дубли отсекаются автоматически.

## Как добавить новую игру

1. Создайте `server/games/моя-игра.js` с функциями `create`, `action`, `view`, `isOver`, `results` (по образцу `whoami.js`). `results` возвращает очки катки по игрокам — из них марафон считает места.
2. Подключите её в `server/index.js` в объекте `GAMES`.
3. Добавьте функцию отрисовки в `public/app.js` (по образцу `rCroc`) и обработчики кнопок.

## Структура

```
server/index.js      — сервер: комнаты, игроки, хост, подарки
server/wallet.js     — монеты: начисление за время в игре, хранение в data/wallets.json
server/gifts.js      — каталог подарков, проверка, списание, активные подарки на аватарках
server/games/*.js    — логика каждой игры (сервер решает, кто что видит)
server/words.js      — словари
public/              — интерфейс (HTML/CSS/JS, без сборки)
test/smoke.js        — боты, которые прогоняют все игры
```

Сервер отправляет каждому игроку только то, что ему положено видеть: агенты в Коднеймс не получают цвета карт, шпион не получает локацию — подсмотреть через консоль браузера не выйдет.
