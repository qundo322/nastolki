# Как выложить сайт в интернет (бесплатно)

Итог: сайт по адресу вида `https://nastolki-svoi.onrender.com`, с HTTPS, работает в любом браузере и на телефоне.
Хостинг — **Render**, бесплатный тариф, карта не нужна. Код хранится на **GitHub**.

## Что делаешь ты (≈10 минут)

1. **GitHub-аккаунт.** Если нет — зарегистрируйся на https://github.com/signup.
2. **Пустой репозиторий.** Открой https://github.com/new → Repository name: `nastolki` → **Public** → ничего не отмечай (без README) → **Create repository**.
3. **Подключи GitHub к Claude** (чтобы я сам залил код): claude.ai → Настройки → Коннекторы → GitHub → подключить и дать доступ к репозиторию `nastolki`. Напиши мне «готово» и свой ник на GitHub.
   - Если подключать не хочешь: распакуй архив, на странице репозитория нажми **uploading an existing file** и перетащи всё содержимое папки `party-games`, **кроме** `node_modules` → **Commit changes**.
4. **Деплой одной кнопкой.** Открой ссылку (подставь свой ник):
   `https://render.com/deploy?repo=https://github.com/ТВОЙ_НИК/nastolki`
   → **Sign in with GitHub** → Render покажет сервис `nastolki-svoi` (Free) → **Apply / Deploy Blueprint**.
5. Подожди 3–5 минут, пока статус станет **Live**. Адрес сайта — вверху страницы сервиса (`https://nastolki-svoi.onrender.com`; если имя занято, Render добавит к нему несколько символов).

## Что делаю я

- Заливаю код в репозиторий (если подключён GitHub).
- После деплоя проверяю, что сайт отвечает.
- Любые правки дальше: ты пишешь мне → я обновляю код в GitHub → Render сам пересобирает сайт за 2–3 минуты. Ничего делать не нужно.
- Аватарки: присылаешь картинки — я кладу их в `public/avatars/` и выкладываю.

## Что важно знать про бесплатный тариф

- **Засыпает через 15 минут без игроков.** Первый заход после этого грузится ~1 минуту (страница загрузки Render). Совет: открой сайт за минуту до игры.
- Пока кто-то в комнате — не засыпает.
- Когда сервер уснул, комнаты пропадают — просто создай новую.
- Лимит — 750 часов в месяц на аккаунт: этого хватает одному сервису на весь месяц.

## Домен

- Бесплатно: поддомен `*.onrender.com` с HTTPS — уже достаточно, чтобы кидать ссылку друзьям.
- Свой домен (например, `nastolki.fun`) покупается отдельно у регистратора, обычно это несколько долларов в год; подключается в Render: Settings → Custom Domains. Это по желанию, можно сделать потом.

## Если что-то пошло не так

- В Render открой сервис → **Logs** и пришли мне скриншот — разберусь.
- «Комната не найдена» после паузы — сервер перезапускался, создай новую комнату.
